# 上海田子坊 Citywalk 攻略 🏮

> 武汉高铁出发 · 2 人版 · 双行程方案（当日往返 / 住一晚）

一个完整、可发布的城市漫游攻略站点。**4 个页面 + 1 个公共样式 + 1 个项目说明**，纯静态 HTML + CSS，无框架、无构建工具，浏览器直接打开即可。

## 📁 项目结构

```
citywalk/
├── index.html          # 攻略首页：高铁交通、双版本行程、酒店、预算、贴士

├── README.md           # 本文件

```

**文件大小**：合计约 110 KB，远低于任何静态托管平台限额。

## 🎨 设计要点

- **色板**：暖白背景（`#faf6f0`）+ 主题橘红（`#c2542e`）+ 墨绿（`#3d6b5e`）+ 金黄（`#d9a441`），全部定义在 `style.css` 顶部的 `:root`，可一处改全站换色。
- **字体**：PingFang SC / Hiragino Sans GB / Microsoft YaHei 系统字体栈，无网络字体依赖。
- **交互**：仅 `index.html` 含 10 行原生 JS（双版本行程切换开关），其他页面纯静态。
- **SVG 地图**：5 张原创 SVG 示意图（封面动线 / 觅食动线 / 三弄堂分布 / 建筑分布 / 石库门结构），纯文字+几何绘制，无外部资源。
- **响应式**：≤600px 自动单列、SVG 横向滑动、导航收紧。
- **打印**：CSS 媒体查询支持直接 `Ctrl+P` 输出干净纸版。

## 🌍 部署上线

把 4 个 HTML + `style.css` 五个文件一起拖到任意静态托管平台即可，**不需要 Node 环境，不需要打包**。

| 平台 | 难度 | 链接有效期 | 推荐场景 |
|---|---|---|---|
| **Netlify Drop** ⭐ | ★ | 登录后永久 | 临时分享 / 快速预览 |
| **GitHub Pages** | ★★ | 永久 | 长期托管、可绑域名 |
| **Vercel** | ★★ | 永久 | CDN 更快、专业感 |
| **Cloudflare Pages** | ★★ | 永久 | 国内访问更稳 |

### 部署前必查

- [ ] 6 个文件齐全（5 个项目文件 + README）
- [ ] 所有文件名**小写英文**（不要用中文文件名）
- [ ] `index.html` 放仓库根目录（GitHub Pages 必须）
- [ ] 浏览器硬刷新（`Ctrl+F5` / `Cmd+Shift+R`）测试

## ✏️ 修改内容

### 网页端直接改（最简单）

GitHub：打开文件 → 右上角铅笔 ✏️ → 网页里直接改 → 底部 `Commit changes` → 2 分钟后自动上线。

### 改全站配色

只改 `style.css` 开头的色板：

```css
:root{
  --terra:#c2542e;   /* 主题橘红（按钮/标题/时间线） */
  --tea:#3d6b5e;     /* 墨绿（表格头/标签） */
  --gold:#d9a441;    /* 金黄（点缀/提示框） */
}
```

例如中秋换金色主题：把 `--terra` 改成 `#b8860b`、`--tea` 改成 `#5c4a1e`，全站瞬间换装。`index.html` 因为内联了样式，色板定义需要同步改顶部。

### 加新页面（比如"武康路篇"）

1. 复制 `architecture.html` 改名为 `wukang.html`
2. 替换正文内容
3. 在 4 个现有页面的顶部导航 `<nav class="topnav">` 区各加一行 `<a href="wukang.html">🌳 武康路</a>`
4. 在首页 `出发前功课` 区照抄一张卡片
5. 样式自动继承，无需额外 CSS

## 🔧 维护速查

| 症状 | 原因 | 解法 |
|---|---|---|
| 页面全是裸文字无样式 | `style.css` 没传或大小写不对 | 检查仓库文件名 |
| 点链接 404 | 文件名与链接大小写不一致 | 全部统一小写 |
| 改了没变化 | CDN / 浏览器缓存 | `Ctrl+F5`，等 5 分钟 |
| SVG 在小屏挤成蚂蚁 | 已默认加补丁 | 检查 `style.css` 末尾的 `@media (max-width:600px)` |
| `index.html` 切换开关不工作 | JS 没加载完 | 浏览器控制台查看是否有错误 |
